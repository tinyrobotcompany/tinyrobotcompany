## About the studio

Tiny Robot Company is the studio name for **Simon Holmes** — a full-stack GenAI engineer who spends the day writing model code and the evening cutting PCBs. The through-line: small, self-contained systems that combine software intelligence with a physical response.

Consulting slots open a few times a year — see [tinyrobotcompany.io](https://tinyrobotcompany.io) or reach out at **hello@tinyrobotcompany.io**.
